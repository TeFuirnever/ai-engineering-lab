# snapshots · 教学代码快照

本目录存放每期课程专用的**裁剪代码快照**。每份快照都是从上游 Apache-2.0
开源项目裁剪出的小体积子集，用于让学员在有限时间内聚焦相关代码。

## 每份快照必须包含

| 文件 | 作用 |
|---|---|
| `LICENSE` | Apache-2.0 许可原文，与上游逐字节一致 |
| `NOTICE.md` | 上游版权声明，逐字节一致 |
| `THIRD-PARTY-NOTICES.md` | 第三方依赖完整署名，**原样全份，不摘录** |
| `version-lock.json` | 源仓版本、裁剪清单、逐文件 SHA-256、工具链版本 |

## 状态

快照正在制作与复核中，通过验收后发布到本目录。当前发布：无。
