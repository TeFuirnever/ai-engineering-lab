# ai-engineering-lab

**AI Engineering 动手实验课** —— Spec-Driven Development、Context Engineering、Agentic Coding。

一门以「动手为主」的实战课：每期给一个真实代码仓库里的真实问题，学员要在
限定时间内完成**定位 → 修复 → 验证 → 举证**的完整闭环。

## 这门课教什么

不是听概念，是练手感。每期 180 分钟里 **115 分钟是自己动手**，讲师只讲 30 分钟、
演示 20 分钟，剩下 15 分钟复盘。

课程贯穿三条主线：

| 主线 | 训练什么 |
|---|---|
| **Spec-Driven Development** | 先写清「什么算做完」，再动手；验收判据可执行、可复评 |
| **Context Engineering** | 在陌生大代码库里高效取证：知道看哪、怎么少读、怎么不被无关信息带跑 |
| **Agentic Coding** | 与 AI 编码工具协作：拆任务、给约束、验结果、担责任 |


## 一个典型的动手任务长什么样

1. **任务卡**告诉你现象：某功能在特定条件下不按预期工作
2. 你拿到一份**裁剪过的代码快照**——不是玩具，是真实项目的真实模块
3. 你要自己**定位**病灶（这一步最难，也最有价值）
4. 给出**修复**，改动尽量小
5. 跑**公开测试**自查，再按评分表准备**证据包**

评分看重的不是「修好了」，而是「你怎么证明你修对了」。
